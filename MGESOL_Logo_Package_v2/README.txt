MGESOL LOGO PACKAGE

This package contains the approved MGESOL logo prepared for website, social media, email, document, and print use.

Start with 09_Brand_Reference/MGESOL_Size_and_Usage_Guide.txt for exact dimensions and recommended use.

Use the SVG files whenever a service accepts vector artwork. Use PNG files for social media and most website uploads.

For LinkedIn, use 02_LinkedIn/MGESOL_LinkedIn_Company_Logo_400x400.png. It is specifically re-proportioned for a square company-logo slot so the mark fills the frame.
